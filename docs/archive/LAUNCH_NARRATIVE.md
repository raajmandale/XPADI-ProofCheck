# Launch Narrative

## Core hook
Checksums prove a file did not change. XPADI ProofCheck asks whether data is ready to survive failure.

## Positioning
XPADI ProofCheck™ introduces Recovery Readiness as a public, developer-testable concept. It sits between integrity, backup verification, and survivability thinking.

## What to show
1. Run a file proof.
2. Show Recovery Readiness.
3. Show Single Point Dependency.
4. Export manifest.
5. Verify file against manifest.

## What not to say
Do not expose internal ecosystem names, secret architectures, recovery protocols, or sovereign/security layers.
