# TRANSCRIPT Proof Chain V4

1. **INPUT** — A file, file group, folder, or transcript request enters the public ProofCheck surface.
2. **HASH** — SHA-256 creates a public identity baseline.
3. **PROOF** — Proof JSON records the observable identity and integrity state.
4. **EVIDENCE** — Markdown evidence translates the proof into human-readable form.
5. **REPORT** — HTML report creates reviewable output.
6. **CONTINUITY** — Continuity artifact records that evidence remains observable after execution.
